A quick and advanced file searcher built with Python using only built-in libraries.

You can filter on all of these:
- Type: File/Folder/Both
- Regex file name patterns
- Advanced file name exclusion
- File contents
- Min/max file size
- Modified within # days
- Created within # days
- Limit to a certain depth (number of folders down)
- Sibling files/folders!
- Sibling file contents!

Additional QoL features
- Search settings save to JSON
- Export search results to a TXT
- Open the file in Explorer or simply copy the name or path!
