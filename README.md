# BetterSearch: Enterprise-grade file searcher and manager.
Light-weight, fast and advanced. Search for files or duplicates using many advanced filters. You can easily manage the results, too!
If you work a lot with files, or, need to manage your 9.5-year-old family photo's back-up HDD, BetterSearch is your go-to.
###### Latest version: v1.1.0
[![Downloads](https://img.shields.io/github/downloads/moonlight-stream/moonlight-qt/total)](https://github.com/moonlight-stream/moonlight-qt/releases)
 
### Why BetterSearch?
Traditional search tools are often slow and cannot filter by complex metadata or perform batch operations on results. BetterSearch gives you granular control over your file system without the indexing overhead.
- Built for power-users, intuitive for all
- Zero dependencies: just run and go
- Advanced filtering: every bit is important
- Batch management: update thousands of files in one go

### Who is BetterSearch for?
- Anyone: Find duplicate files across your workspaces or use every known piece of info to narrow down the search for lost files
- Developers: Find outdated configs or files acting on one-another
- Archivists: Navigate complex file systems for duplicates or group files for research
- Recoverers: Move and copy files securely with MD5 integration

## Getting started
1. Download and run BetterSearch using [Python](https://www.python.org/downloads/) (3.7 or up)
2. Select a folder at the top-left
3. Under "Basic Filters", type something you want to find. Use * for wildcards (i.e. wishlist *.doc)
4. Click [Start Search] at the bottom and wait for it to show your files! (i.e. wishlist 2006.doc)
5. Right-click the result and select [Open Location] to view it in File Explorer.

## Technical Specifications
- Lightweight and fast at just `66.2 kB`
- Supports Windows, Linux & MacOS
- All data is processed locally
- Runs using Python 3.7 and up

## The range of filters includes:
- Type: File/Folder/Both
- Regex file name patterns
- Advanced file name exclusion
- File contents
- Min/max file size
- Modified within `#` days
- Created within `#` days
- Limit to a certain depth (number of folders down)
- Sibling files/folders!
- Sibling file contents!

### Additional QoL features
- Settings save to JSON
- Export search results as a TXT
- Batch file management
